🐧 Linux Essentials for Cloud Engineers

October 17, 2026

Every cloud server runs Linux under the hood. Whether you're SSHing into an AWS EC2 instance or exec-ing into a Docker container, these commands are your daily toolkit.

Top Commands You Must Know

  • curl -I http://host/ — check HTTP headers & status
  • dig @ns -p 1053 host.cloud.local +short — DNS query
  • docker exec -it container sh — shell into a container
  • ss -tlnp — show listening ports
  • journalctl -u nginx --no-pager — service logs

Quick System Health Check Script

#!/bin/sh
echo "=== CPU ===" && top -bn1 | grep "Cpu(s)"
echo "=== Memory ===" && free -h
echo "=== Disk ===" && df -h /
echo "=== Containers ===" && docker compose ps

In MyMiniCloud we use Prometheus + Grafana to automate this monitoring — but knowing the raw Linux commands is invaluable when something breaks.
