Microservices & Kiến trúc API Gateway

NGUYÊN LÝ ĐỊNH TUYẾN NGƯỢC, CÂN BẰNG TẢI ROUND-ROBIN VÀ BẢO MẬT OIDC JWT

HÌNH 3.1: HẠ TẦNG VI DỊCH VỤ PHÂN TÁN VỚI ĐIỂM TIẾP NHẬN TRUY CẬP ĐƠN NHẤT API GATEWAY

Trong kỷ nguyên của các ứng dụng quy mô lớn, kiến trúc nguyên khối (Monolithic) dần bộc lộ giới hạn về khả năng mở rộng và triển khai liên tục. Kiến trúc Vi dịch vụ (Microservices) nổi lên như một tiêu chuẩn công nghiệp nhằm chia nhỏ ứng dụng thành các dịch vụ độc lập, tự chủ và có khả năng phục hồi cao.

1. Vai trò của API Gateway / Reverse Proxy

Khi số lượng vi dịch vụ tăng lên, việc để máy khách (Client) giao tiếp trực tiếp với từng dịch vụ sẽ gây ra sự phức tạp về bảo mật, mạng và CORS. API Gateway đóng vai trò là cửa ngõ duy nhất (Single Point of Entry) với các chức năng tối quan trọng:

  • Định tuyến đường dẫn (Path Routing): Phân tích URI để chuyển tiếp chính xác đến dịch vụ phụ trách (ví dụ: /api/ trỏ về Flask API, /auth/ trỏ về Keycloak, / trỏ về Web Frontend).
  • Cân bằng tải (Load Balancing): Phân phối lưu lượng đồng đều theo thuật toán Round-Robin qua cụm nhiều máy chủ web để chống nghẽn và tăng độ sẵn sàng.
  • Bảo mật tập trung: Che giấu cấu trúc mạng nội bộ, ngăn chặn truy cập trực tiếp vào các dịch vụ lõi như CSDL MariaDB hay Storage.

2. Cơ chế cân bằng tải Round-Robin trong MiniCloud

Hệ thống cấu hình Nginx upstream định tuyến luân phiên 1:1 giữa hai phiên bản máy chủ web-frontend-server1 và web-frontend-server2:

upstream web_backend { server web-frontend-server1:80; server web-frontend-server2:80; } server { listen 80; location / { proxy_pass http://web_backend; proxy_set_header Host $host; add_header X-Upstream-Addr $upstream_addr always; } }

3. Xác thực không trạng thái với OIDC & JWT

Hệ thống tích hợp Keycloak chuẩn OpenID Connect (OIDC). Khi sinh viên đăng nhập thành công, Keycloak cấp phát một JSON Web Token (JWT) được ký số bằng thuật toán mã hóa bất đối xứng RS256. Ứng dụng Backend Flask chỉ cần nạp khóa công khai (JWKS) từ Keycloak để xác thực chữ ký token mà không cần truy vấn lại CSDL phiên (Stateless Authentication).
