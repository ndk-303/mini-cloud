Hạ Tầng Dịch Vụ Đám Mây

01. WEB FRONTEND CLUSTER PORT 8001 / 8002

2 máy chủ Nginx chạy tĩnh, phân phối tải Round-Robin 1:1 theo chuẩn Mở rộng 10.

TRANG CHỦ CLOUD → /metrics ↗
02. APPLICATION BACKEND PORT 8081

Microservice Python Flask xử lý nghiệp vụ, CRUD sinh viên và xác thực OIDC JWT.

/STUDENT/ → /api/hello ↗
03. MARIADB RDBMS PORT 3306

CSDL quan hệ lưu trữ bền vững bảng students và blogs kèm auto-seeding.

QUẢN TRỊ SINH VIÊN → studentdb
04. KEYCLOAK IDENTITY PORT 8080

Hệ thống quản lý danh tính OIDC/OAuth2 cấp phát token JWT & phân quyền RBAC.

ADMIN CONSOLE → realm: master
05. OBJECT STORAGE (S3) PORT 9000 / 9001

SeaweedFS S3-compatible Blob Storage lưu ảnh bìa bài viết và tệp đính kèm.

STORAGE WEB UI → SeaweedFS
06. INTERNAL DNS RESOLVER PORT 1053

Máy chủ Bind9 phân giải tên miền nội bộ zone cloud.local cho các container.

ZONE CLOUD.LOCAL UDP 53
07. PROMETHEUS METRICS PORT 9090

Thu thập chỉ số định kỳ (time-series) từ Node Exporter và các Web nodes.

XEM TARGETS UP → 100% UP
08. GRAFANA DASHBOARD PORT 3000

Trực quan hóa tài nguyên CPU, RAM và lưu lượng mạng hệ thống thời gian thực.

MỞ DASHBOARD → admin/admin
09. API GATEWAY PROXY PORT 80
