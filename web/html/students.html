DANH SÁCH ENDPOINTS CHUẨN HTTP 200
  • GET /student/ — Trả về JSON danh sách sinh viên chuẩn theo yêu cầu Mở rộng 9.
  • GET /api/students-db — Lấy toàn bộ bản ghi thực tế từ bảng students trong MariaDB.
  • POST /api/students-db — Thêm sinh viên mới (Yêu cầu Header Authorization: Bearer <admin_jwt>).
  • DELETE /api/students-db/<id> — Xóa sinh viên theo ID (Chỉ tài khoản quyền Admin thực hiện).
